# Godot Engine教育ソフト - エディタ拡張アプローチ計画書

## アプローチ概要

Godotエディタの拡張機能（EditorPlugin）を活用し、エディタ自体を教育ソフトとして改造する。

### 核心的な利点

1. **既存のエディタ機能を活用**
   - シーンツリー表示（SceneTreeDock）
   - プロパティインスペクタ（EditorInspector）
   - ファイルシステムドック（FileSystemDock）
   - デバッガ機能
   - すべてが既に実装済み！

2. **ゲームプレビュー機能の統合**
   - GameViewPluginによるエディタ内ゲーム実行
   - embedded_processでの埋め込み表示
   - プロセス起動の問題が解決される

3. **全画面表示が可能**
   - メインスクリーン占有モード
   - ディストラクションフリーモード
   - 独立ウィンドウ化

4. **クロスプラットフォーム対応**
   - ✅ Windows, macOS, Linux（完全サポート）
   - ✅ Web（Godotエディタ自体のWeb版として動作可能）
   - ⚠️ モバイル（エディタは非対応）

**education_plugin.gd**:
```gdscript
@tool
extends EditorPlugin

var education_main_view: Control
var window_wrapper: Node  # WindowWrapper for floating window
var game_view_integrated: bool = false

func _enter_tree() -> void:
    # メインビューを作成
    education_main_view = preload("res://addons/education_system/ui/education_main_view.tscn").instantiate()

    # EditorInterfaceから既存機能にアクセス
    var editor_interface = get_editor_interface()

    # メインスクリーンとして追加
    get_editor_interface().get_editor_main_screen().add_child(education_main_view)

    # 初期化時は非表示
    education_main_view.visible = false

    # ゲームビューを統合
    _integrate_game_view()

    print("Education System Plugin loaded!")

func _exit_tree() -> void:
    if education_main_view:
        education_main_view.queue_free()

# メインスクリーンとして認識される
func _has_main_screen() -> bool:
    return true

func _get_plugin_name() -> String:
    return "Education"

func _get_plugin_icon() -> Texture2D:
    return preload("res://addons/education_system/icon.svg")

# エディタがこのプラグインのタブを選択したときに呼ばれる
func _make_visible(visible: bool) -> void:
    if education_main_view:
        education_main_view.visible = visible
        if visible:
            _on_education_mode_activated()

func _on_education_mode_activated() -> void:
    # ディストラクションフリーモードを有効化（オプション）
    # get_editor_interface().set_distraction_free_mode(true)

    # 学習対象シーンをロード
    if not get_editor_interface().get_edited_scene_root():
        get_editor_interface().open_scene_from_path("res://learning_target/test_scene.tscn")

func _integrate_game_view() -> void:
    # GameViewPluginの機能を活用
    # エディタのゲームプレビュー機能を教育UIに統合
    var game_view_container = education_main_view.get_node("GamePreviewPanel/GameViewContainer")

    # EditorRunを使ってゲームを起動
    # embedded_processで埋め込み表示
    game_view_integrated = true

# シーン変更時に通知を受ける
func _scene_changed(scene_root: Node) -> void:
    if education_main_view and education_main_view.visible:
        education_main_view.on_scene_changed(scene_root)

# ノード選択時に通知を受ける
func _edit(object: Object) -> void:
    if education_main_view and education_main_view.visible:
        education_main_view.on_object_selected(object)
```

#### Phase 2: メインビューUI実装

**education_main_view.gd**:
```gdscript
@tool
extends Control

# エディタ機能への参照
var editor_interface: EditorInterface
var inspector: EditorInspector
var scene_tree_dock: Control

# UI要素
@onready var tutorial_panel: Panel = $HSplitContainer/LeftPanel/TutorialPanel
@onready var game_preview_panel: Panel = $HSplitContainer/CenterPanel/GamePreviewPanel
@onready var properties_panel: Panel = $HSplitContainer/RightPanel/PropertiesPanel
@onready var console_output: RichTextLabel = $BottomPanel/ConsoleOutput

var current_lesson: Resource
var selected_node: Node

func _ready() -> void:
    if Engine.is_editor_hint():
        _setup_editor_integration()
        _load_lesson("res://addons/education_system/lessons/lesson_01_nodes.tres")

func _setup_editor_integration() -> void:
    # EditorPluginから渡される
    editor_interface = EditorPlugin.new().get_editor_interface() if not editor_interface else editor_interface

    # 既存のインスペクタを統合
    if editor_interface:
        inspector = editor_interface.get_inspector()

        # カスタムインスペクタを作成するか、既存のものを埋め込む
        _embed_inspector()

func _embed_inspector() -> void:
    # プロパティパネルに既存のインスペクタを表示
    # または、カスタムインスペクタを作成
    var custom_inspector = VBoxContainer.new()
    custom_inspector.name = "CustomInspector"
    properties_panel.add_child(custom_inspector)

func on_scene_changed(scene_root: Node) -> void:
    # シーンが変更されたときの処理
    _update_scene_tree_display(scene_root)
    console_output.append_text("[color=green]Scene changed: %s[/color]\n" % scene_root.name)

func on_object_selected(object: Object) -> void:
    # オブジェクトが選択されたときの処理
    if object is Node:
        selected_node = object
        _display_node_properties(object)
        _highlight_in_tutorial(object)

func _update_scene_tree_display(root: Node) -> void:
    # シーンツリーの表示を更新
    var tree_view = tutorial_panel.get_node_or_null("SceneTreeView")
    if tree_view:
        tree_view.build_tree(root)

func _display_node_properties(node: Node) -> void:
    # ノードのプロパティを表示
    if editor_interface:
        editor_interface.inspect_object(node)

    # カスタム表示も追加
    _show_educational_hints(node)

func _show_educational_hints(node: Node) -> void:
    # 教育的なヒントを表示
    var hint_text = ""

    if node is Sprite2D:
        hint_text = """
[b]Sprite2D Node[/b]
- テクスチャを表示するノード
- position, rotation, scale プロパティで制御
- texture プロパティに画像を設定
        """
    elif node is CharacterBody2D:
        hint_text = """
[b]CharacterBody2D Node[/b]
- 物理演算を持つキャラクター
- move_and_slide() で移動
- velocity プロパティで速度を設定
        """

    if hint_text:
        var hint_label = properties_panel.get_node_or_null("HintLabel")
        if hint_label:
            hint_label.text = hint_text

func _load_lesson(lesson_path: String) -> void:
    current_lesson = load(lesson_path)
    if current_lesson:
        _display_lesson(current_lesson)

func _display_lesson(lesson: Resource) -> void:
    # レッスン内容を表示
    var lesson_text = tutorial_panel.get_node("LessonText")
    if lesson_text:
        lesson_text.text = lesson.get("content", "")

    # 対応するシーンをロード
    var scene_path = lesson.get("scene_path", "")
    if scene_path and editor_interface:
        editor_interface.open_scene_from_path(scene_path)

# ゲームプレビューの制御
func play_game() -> void:
    if editor_interface:
        editor_interface.play_current_scene()

func stop_game() -> void:
    if editor_interface:
        editor_interface.stop_playing_scene()

# コンソール出力のキャプチャ
func _capture_print_output() -> void:
    # print() の出力をキャプチャしてコンソールに表示
    # Godotのエディタ出力をリダイレクト
    pass
```

@tool
extends Panel

var editor_interface: EditorInterface
var embedded_game_window: Window
var is_game_running: bool = false

@onready var play_button: Button = $Toolbar/PlayButton
@onready var stop_button: Button = $Toolbar/StopButton
@onready var game_container: SubViewportContainer = $GameContainer

func _ready() -> void:
    play_button.pressed.connect(_on_play_pressed)
    stop_button.pressed.connect(_on_stop_pressed)
    stop_button.disabled = true

func _on_play_pressed() -> void:

        _setup_embedded_process()
    else:
        # SubViewportを使ったフォールバック
        _setup_subviewport_preview()

func _setup_embedded_process() -> void:
    # platform/macos/editor/embedded_game_view_plugin.h の機能を活用
    # C++側の実装が必要
    pass

func _setup_subviewport_preview() -> void:
    # SubViewportでゲームをプレビュー

## レッスンデータ構造

**lesson.gd** (Resource):
```gdscript
extends Resource
class_name EducationLesson

@export var lesson_id: String
@export var title: String
@export_multiline var content: String
@export var scene_path: String
@export var target_node_paths: Array[NodePath]
@export var exercises: Array[Dictionary]
@export var hints: Array[String]
@export var next_lesson: String

func get_exercise(index: int) -> Dictionary:
    if index < exercises.size():
        return exercises[index]
    return {}

func validate_exercise(index: int, user_solution: Variant) -> bool:
    var exercise = get_exercise(index)
    if exercise.has("validator"):
        var validator = exercise.validator as Callable
        return validator.call(user_solution)
    return false
```

## Web版エディタでの実装

Godot 4.x にはWeb版エディタ（Godot Editor running in browser）が存在します。

### Web版の制限事項

1. **プロセス起動**: 不可（`OS.create_process()` が使用不可）
2. **GameView埋め込み**: iframe制限により困難
3. **独立ウィンドウ**: ブラウザのポップアップ制限

### Web版での回避策

```gdscript
func _integrate_game_view_web() -> void:
    # SubViewportを使用した代替実装
    var viewport = SubViewport.new()
    viewport.size = Vector2i(800, 600)
    viewport.render_target_update_mode = SubViewport.UPDATE_ALWAYS

    game_container.add_child(viewport)

    # 学習対象シーンをロード
    var scene = load("res://learning_target/test_scene.tscn")
    if scene:
        var instance = scene.instantiate()
        viewport.add_child(instance)
```

## まとめ

### アプローチの評価

#### ✅ 主な利点

1. **既存機能の完全活用**
   - シーンツリー、インスペクタ、デバッガなどが全て無料で使える
   - ゼロから実装する必要がない

2. **ゲーム実行との統合**
   - エディタのゲームプレビュー機能をそのまま活用
   - embedded_processで埋め込み表示が可能

3. **開発効率**
   - EditorPluginとして実装するだけ
   - GDScriptで完結（一部C++拡張可能）

4. **保守性**
   - Godotエディタの更新に追従しやすい
   - 標準的なプラグイン形式

#### ⚠️ 制限事項

1. **プラットフォーム制限**
   - モバイル・コンソールではエディタが動作しない
   - デスクトップ + Web のみ

2. **配布形態**
   - エディタのバイナリと一緒に配布
   - スタンドアロンアプリではない

3. **カスタマイズ限界**
   - エディタUIの根本的な変更は困難
   - エディタの枠組みの中での実装

### 計画書1との比較

| 項目 | 計画書1（SubViewport） | 計画書2（EditorPlugin） |
|---|---|---|
| **実装難易度** | 中 | 低 |
| **既存機能活用** | 不可 | ✅ 完全活用 |

### 開発開始ステップ

```bash
# 1. プラグインディレクトリを作成
mkdir -p addons/education_system/ui

# 2. plugin.cfg を作成
cat > addons/education_system/plugin.cfg << EOF
[plugin]
name="Education System"
description="Interactive Godot learning environment"
author="Your Name"
version="1.0"
script="education_plugin.gd"
EOF

# 3. education_plugin.gd を作成（上記のコード例を参照）

# 4. Godotエディタで有効化
# プロジェクト設定 > プラグイン > Education System を有効化
```

このアプローチにより、Godotの強力なエディタ機能を教育ソフトとして最大限に活用できます。
